Locked Cross-App Decisions

Non-Negotiable Implementation Rules

Employee Experience

Mobile: Sales / Chat / raised Add Sale / Tasks / Menu.
Desktop: collapsible sidebar, personal favorites, density settings and true full-width Chat.
Presence: Idle Detection is mandatory; unsupported or denied access blocks the working app.
Time: operational timestamps display in America/Chicago / Central Time.
Offline: safe read-only caching and selected queued actions only; sensitive actions remain blocked.

Security & Management

Permissions: Sales Agent, Sales Supervisor, Sales Manager and Owner.
Audit: security and management actions use role-appropriate durable audit records.
Owner recovery: fresh authentication + master recovery credential + TOTP where designed.
Production: staged/atomic deployment, readiness checks, validation and rollback governance.
Backups: daily encrypted 12:30 AM CT backups with seven-day retention and protected recovery.
