Navigation System

Mobile shell rules

Five persistent tabs: Sales, Chat, raised Add Sale, Tasks, and Menu.
Menu is role-aware: management tools appear only for roles that can use them.
Favorites stay near the top: users can pin frequently used forms, resources, pages, and shortcuts.
Badges surface action: unread chat, tasks, required announcements, approvals, and support updates are visible without opening each section.
Add Sale is always one tap away: the center action opens as a bottom sheet rather than navigating the user away from their current page.
Desktop and mobile are intentionally different: the mobile experience favors large touch targets and shallow navigation instead of shrinking the desktop sidebar.
