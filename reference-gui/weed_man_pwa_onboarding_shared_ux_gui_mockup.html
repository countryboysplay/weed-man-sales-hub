First Launch

Install the Sales Hub once, then use it like an app.

The first-run flow is intentionally short. Employees sign in, install the PWA when supported, enable notifications, pass the required Idle Detection compatibility and permission check, review their status and shift, then land on the Sales Dashboard.

Idle Detection
Required for presence tracking before the employee can enter the working app.
REQUIRED
Idle Detection is required.
If the browser does not support Idle Detection, or the user denies permission, the working app remains blocked. The user is directed to enable the permission or switch to a supported browser/device. Fallback activity signals may supplement presence data, but they do not replace the required Idle Detection permission.
